I work at INRAE's IRHS institute in Angers, France, developing open-source tools for digital phenotyping.

FrontVeg V2

2026 · INRAE / IRHS

Geometry-aware, training-free framework for zero-shot plant trait segmentation in trellised crops. Combines Depth Anything V2 with SAM3 via Valley-Aware Depth Thresholding and Graph-Based Mask Assembly. Published on PyPI and available as a Napari plugin.

Python SAM3 Depth Anything
🤸

Fall Detection System

2022 – 2023 · INRIA Sophia Antipolis

End-to-end fall detection pipeline for the elderly using skeleton-based action recognition on untrimmed videos. Adapted the UNIK framework with MediaPipe Pose on the PKU-MMD dataset, targeting deployment on embedded Raspberry Pi devices.

Python PyTorch Raspberry Pi
🍎

DeepPhenoTree Challenge

Apr – Jul 2026 · INRAE / IRHS

Co-organised a public benchmark on Codabench for apple phenological stage detection across four European orchard sites. Challenge covers 48,320 images and three BBCH phenological stages under real open-field conditions.

Object Detection RT-DETR YOLO Phenotyping
