Best Coding Practices for Researchers

INRAE / IRHS — Angers, France

2026

A lecture and practical course designed to introduce research engineers and scientists to modern software engineering workflows. The course emphasises reproducibility, automation, and collaboration — skills increasingly critical in computational and data-intensive research.

The practical component is built around a mini Flask application project, guiding participants through the full cycle of containerising an application, running automated tests inside containers, and deploying automatically with a CI/CD pipeline.

Topics covered

  • Containerisation with Docker — concepts, images, and containers
  • Writing and running a Dockerfile for a Python application
  • Automated testing inside containers
  • Publishing images to a container registry
  • GitLab CI/CD pipeline design and automation
  • Practical project: end-to-end CI/CD for a Flask web service

Deep Learning for Image Classification

INRAE Staff Training — Angers, France

March 3–5, 2026

A three-day intensive hands-on training course for INRAE research staff with limited prior exposure to deep learning. The course provides a practical pathway from foundational concepts to working image classification models, using real datasets and modern tooling throughout.

Participants leave with a working understanding of convolutional neural network architectures, the transfer learning workflow, and the ability to fine-tune pre-trained models on their own datasets. All exercises are in Python with PyTorch, and the course materials are published as an open-source repository.

Topics covered

  • Introduction to deep learning: perceptrons, activation functions, backpropagation
  • Convolutional Neural Networks (CNNs): architecture and design principles
  • Classical CNN architectures: ResNet, VGG
  • Transfer learning: feature extraction and fine-tuning strategies
  • Practical image classification pipeline in PyTorch
  • Evaluation, overfitting diagnosis, and regularisation
